# IP 全套周边

成品：上传一个 IP 形象，生成一张八类周边的全家福，摆放在三级看台式展台上；不是角色三视图、表情包或整套 IP 设计规范。

## 固定视觉要求

- 保留 IP 五官、比例、配色及标志特征，按产品材质和工艺适配，不能重新设计角色。
- 默认八类：抱枕、马克杯、帆布包、手机壳、钥匙扣、徽章、笔记本、包装盒。
- 浅色三级看台，后高前低，大件靠后、小件靠前；轻微俯视的三分之四视角，完整展示产品及 IP 图案。
- 柔和棚拍光、真实材质、明确落台与接触阴影，统一设计语言，互不遮挡。

## 可变项

IP 形象、台面配色、已知品牌文字以及用户明确要求替换的周边品类。未指定时使用上述八类。画幅以用户指定为准，未指定时可建议竖版 3:4，不改变三级看台结构。

## 短模板

```text
参考上传的IP，生成抱枕、马克杯、帆布包、手机壳、钥匙扣、徽章、笔记本和包装盒的周边全家福。保留IP五官、比例、配色与标志特征，材质随产品适配。所有单品摆放在浅色三级看台式展台上，后高前低，大件靠后、小件靠前，错落有序、疏密均衡；每件稳固落台，产品正面与IP图案清晰可见。轻微俯视的三分之四视角，突出阶梯深度。简洁背景、柔和棚拍光、真实材质与接触阴影，商业产品摄影质感。仅使用已提供的品牌文字。
```

## 检查重点

数清八类是否齐全，再核对每件上的 IP 特征。台阶应有明确三级高差，产品不悬空、不穿插、不靠不合理比例挤进画面。不要变为九宫格、平铺图、十二类设计物料或独立产品图片集合。
