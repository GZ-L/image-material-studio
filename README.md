# 图片物料生成 · Image Material Studio

一个面向 Codex 的图片物料 Skill：先了解用户的用途和素材，再按最终成品推荐方案，生成图片或可复制的精简提示词。

适合商品宣传、自媒体配图、IP 周边展示、节日活动海报和照片风格转换。它把五套提示词整理成有明确输入、视觉要求和检查步骤的工作流程，减少每次从头描述的成本。

## 支持的五种成品

| 方案 | 最终效果 | 主要输入 |
|---|---|---|
| **艺术海报** | 商品主体清晰，背景融合朦胧色雾、油画肌理、岩彩颗粒和少量金箔微光；根据商品调性调整，不限于香水 | 商品图及用途；品牌和文案可选 |
| **图片分解** | 食材或有依据的部件垂直悬浮分层，配中文引线标注 | 菜品图、部件资料或明确清单 |
| **IP 全套周边** | 抱枕、马克杯、帆布包、手机壳、钥匙扣、徽章、笔记本和包装盒，排列在三级看台上的一张全家福 | 已确认的 IP 形象 |
| **节日海报** | 巨物内部藏有微缩世界，结合微型人物、蓝橙光色和中英文大字排版 | 节日或主题可选；未提供时默认万圣节并自动拟题 |
| **照片转手绘** | 保留原场景构图，转换为黑色墨线、水粉色块和少量手写涂鸦组成的旅行手账插画 | 待转换的照片 |

IP 全套周边交付的是**一张周边展示图**，不包含生产工程文件、角色三视图或表情包套装。

## 如何工作

1. **了解需求**：目标不明确时，先询问成品用途和已有素材；已提供的信息不重复问。
2. **推荐方案**：展示五类成品，将最合适的一项放在首位并说明理由。
3. **按需执行**：已经指定方案或授权代选时，直接进入制作；只要提示词时不调用生图工具。
4. **检查结果**：核对主体、构图、产品或 IP 特征、文字及约定的物料数量，针对明显偏差进行修正。

默认一次制作所选方案的一张图片。画幅可自行指定；未指定时，艺术海报、图片分解和 IP 周边采用 3:4，节日海报采用 9:16，照片转手绘保留原图比例。

## 在 Codex 中使用

从仓库下载或克隆项目，将包含 `SKILL.md`、`references/`、`assets/` 和 `agents/` 的完整目录命名为 `image-material-studio`，放入本机的：

```text
~/.codex/skills/image-material-studio/
```

如配置了自定义 `CODEX_HOME`，请使用对应的 `skills` 目录。不要只复制 `SKILL.md`，五套方案和节日参考图也需要一起保留。已有同名 Skill 时先备份，再更新。

安装后，在 Codex 中调用：

```text
$image-material-studio
```

若当前聊天尚未识别新安装的 Skill，可重新打开 Codex 或开启新聊天。

### 使用示例

**不确定该做哪种成品：**

```text
$image-material-studio
我想给新上市的咖啡做小红书宣传，有商品图，请帮我推荐合适的方案。
```

**上传 IP 制作全套周边：**

```text
$image-material-studio
根据我上传的 IP，生成一张全套周边展示图，摆在三级看台上，画幅 16:9。
```

**自动拟定节日主题：**

```text
$image-material-studio
帮我生成一张节日海报，主题和文案由你来定。
```

未指定节日时采用万圣节，并使用本项目内置的视觉参考。

**只要精简提示词：**

```text
$image-material-studio
给我一段适用于不同商品的艺术海报提示词，尽量简短，不生成图片。
```

## 输入与使用边界

- **复现已有商品、IP 或照片**：需要对应的目标图片。风格参考图不能替代商品或角色素材。
- **原创概念**：可以依据文字描述设计，但不将其当作真实商品的复现。
- **图片分解**：只使用可辨认或用户明确提供的食材、部件，不推测隐藏配料，也不凭外观图编造内部结构。
- **品牌与活动信息**：保留已提供的准确信息，不虚构卖点、活动地点或电话号码。
- **仅提示词**：不要求先上传素材，可直接给出通用模板。
- **实际生图**：依赖运行环境提供的图像生成或编辑工具。本项目本身不是独立的绘图模型或应用，没有额外的 API 密钥配置项。工具不可用时会明确说明，并交付提示词。

生成质量取决于模型、参考素材和任务复杂度。中文排版、Logo、IP 一致性及精确数量仍需检查；提示词中的比例或“高清”描述不等于已验证的输出尺寸。
